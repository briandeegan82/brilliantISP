Notices for brilliantisp_gpu/ops/reference_math.py and
brilliantisp_gpu/ops/reference_math_data.py

These files adapt, in numerical form only, the float32 natural-log table
and polynomial from glibc's e_logf.c / e_logf_data.c (used as numerical
source material for the _logf_mantissa primitive) and the split-constant
base-10 reduction from Sun Microsystems' fdlibm e_log10f.c. The
adaptation uses the source only as numerical formula/table
configuration; the repository root license (Apache-2.0) is unchanged.
The affected files are licensed conservatively as LGPL-2.1-or-later for
the glibc-derived portions; the fdlibm log10 portion carries Sun's
permissive grant notice below.
