Notice for brilliantisp_gpu/ops/resize_float32.py and
brilliantisp_gpu/kernels/resize_area_float32.cu

These files adapt, in numerical form only, the INTER_AREA downsample
arithmetic from OpenCV 4.11's modules/imgproc/src/resize.cpp (tap-table
construction, integer fast-path accumulation order, and weighted
row/column summation). The adaptation uses the source only as
numerical/algorithmic configuration for a GPU port; the repository
root license (Apache-2.0) is unchanged, and OpenCV's original BSD
3-clause license below is compatible and preserved in full.

Source: https://raw.githubusercontent.com/opencv/opencv/4.11.0/modules/imgproc/src/resize.cpp
